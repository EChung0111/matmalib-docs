    Run metadynamics with PLUMED¶

    mlmd.run_md can add a PLUMED bias to an ASE-compatible potential. Structured CVs generate grid-free well-tempered metadynamics for one or two distances, angles, or torsions, with optional reversible hill-deposition pauses. Explicit grids remain available for normalized COLVAR analysis. Custom PLUMED input supports additional actions. This tutorial covers configuration, native execution, outputs, continuous equilibration, and restart.

    Metadynamics deposits history-dependent hills along selected CVs. Choosing a CV, Gaussian width, deposition interval, and bias strength requires physical knowledge of the process being sampled; faster motion in a chosen CV alone does not establish a converged free-energy surface. See the PLUMED METAD documentation for the method and action options.

    1. Install native PLUMED¶

    Use the repository's environment from its root directory:

    conda env update -n matmalib -f environment.yml
conda run -n matmalib python -m pip check
conda activate matmalib

    It installs the MLMD dependencies plus the native PLUMED kernel, Python bindings, command-line tools, and FFTW. pip install 'matmalib[metadynamics]' supplies ASE and Python bindings for a supplied calculator, but the bindings alone do not include the native kernel. For AIMNet, use the full MLMD setup in the simulation tutorial.

    Browser cells on this page only create configurations and inspect units. Running a simulation needs the local environment; PLUMED and AIMNet are not loaded in the browser.

    2. Understand indices, units, and timing¶

    The two interfaces intentionally use different conventions:

    Quantity MD/geometry interface Generated PLUMED input
    Atom selections fixed_atoms uses zero-based positions CVConfig.atoms and scalar MetadynamicsConfig.atoms use one-based positions
    Length Å nm
    Energy eV kJ/mol
    Time fs ps in HILLS/COLVAR
    Angles Geometry methods commonly return degrees ANGLE, TORSION, and their sigma use radians
    Temperature K K
    Frequency Integration steps pace and colvar_stride are integration-step counts

    Structured distance CVs accept unit="angstrom": matmalib converts their width, optional grid bounds, and inherited pause thresholds to PLUMED's native nm. HILLS/COLVAR and canonical saved metadata remain in nm. The default unit=None retains nm for distance CVs. Custom PLUMED input can select its own units with an initial UNITS directive. See PLUMED UNITS.

    from matmalib import mlmd

cv = mlmd.CVConfig("distance", "DISTANCE", (3, 11), sigma=0.2, unit="angstrom")
meta = mlmd.MetadynamicsConfig(cvs=(cv,), pace=300,
                               colvar_stride=10)
md = mlmd.MDConfig(steps=100000, timestep_fs=0.5,
                   mode="metadynamics", metadynamics=meta)
print("Selected zero-based positions:", tuple(i - 1 for i in cv.atoms))
print("Distance width:", cv.sigma, cv.unit)
print("Hill interval:", meta.pace * md.timestep_fs, "fs")
print("COLVAR interval:", meta.colvar_stride * md.timestep_fs / 1000, "ps")
print("Run duration:", md.steps * md.timestep_fs / 1000, "ps")

    The example reports a 0.2 Å width, 150 fs hill interval, 0.005 ps COLVAR interval, and 50 ps duration. These are illustrative settings, not a validated protocol for a particular molecule. Changing the timestep changes every frequency expressed in physical time unless you adjust the corresponding step counts.

    Use positions in the input atom ordering, not Atom.id, PDB serial numbers, or residue identifiers. Atom selections must contain the required number of unique, valid one-based indices.

    3. Run a small installation check¶

    Save the following as check_metadynamics.py and run python check_metadynamics.py in a new directory. This exercises native PLUMED with ASE's inexpensive EMT calculator and a small copper cell. It is an integration check, not a machine-learning model or a physical free-energy calculation. It avoids downloading model weights.

    from pathlib import Path
from ase.build import bulk
from ase.calculators.emt import EMT
from matmalib import mlmd

out = Path("metad_check")
out.mkdir(exist_ok=True)
simulation = mlmd(calculator=EMT())
meta = mlmd.MetadynamicsConfig(
    cvs=(mlmd.CVConfig("distance", "DISTANCE", (1, 2), sigma=0.2, unit="angstrom"),),
    height_kj_mol=0.1, pace=10,
    biasfactor=10.0, colvar_stride=1,
    hills_file=out / "HILLS",
    colvar_file=out / "COLVAR",
    save_input=out / "plumed.dat",
    log_file=out / "plumed.log",
)
trajectory = simulation.run_md(
    bulk("Cu", cubic=True),
    mlmd.MDConfig(
        steps=100, timestep_fs=0.2, temperature_K=300.0,
        ensemble="NVT", thermostat="langevin", seed=17,
        mode="metadynamics", metadynamics=meta,
        trajectory=out / "trajectory.xyz",
        trajectory_interval=10,
        log_file=out / "md.log",
        log_interval=10,
    ),
)
print("Trajectory:", trajectory)
print("Checkpoint:", simulation.data.checkpoint_file)
print("Final step:", simulation.data.last_step)
print("Resolved PLUMED:")
print("\n".join(simulation.data.plumed_input))

    Expect a streamed XYZ trajectory through step 100, an MD log, a final checkpoint, and PLUMED input/log/HILLS/COLVAR files. The simulation lasts only 20 fs. Re-running with the same names raises instead of silently replacing files; select a new output directory for another check.

    For a molecular MLMD calculation, use simulation = mlmd(...) with appropriate AIMNet weights or another validated ASE calculator, and replace the copper structure with your equilibrated State or extended XYZ path. Choose the CV atoms for that system. The solvation tutorial creates equilibrated.xyz; retain its cell and PBC metadata for a periodic run.

    4. Choose a generated CV and bias¶

    Setting Meaning
    cv="DISTANCE", atoms=(i, j) One scalar separation; sigma and wall positions in nm.
    cv="ANGLE", atoms=(i, j, k) Angle at the middle atom; width and wall positions in radians.
    cv="TORSION", atoms=(i, j, k, l) Signed dihedral using the supplied ordering; width and wall positions in radians.
    height_kj_mol Positive initial hill height.
    pace Positive integer number of integration steps between hills.
    biasfactor Well-tempered factor, strictly greater than one.
    temperature_K Bias temperature; None uses the enclosing MD temperature.
    cv_label, metad_label, wall_label Distinct PLUMED action labels; defaults cv, metad, wall.
    metad_arg, wall_arg metad_arg defaults to all structured CV labels; a two-CV wall needs an explicit wall_arg. Scalar arguments default to cv_label.
    colvar_stride, colvar_arg PRINT frequency and optional comma-separated output references.

    For nonperiodic systems, generated CV input includes NOPBC. For periodic systems PLUMED uses the box supplied at each step. Partial periodicity is rejected: use either no periodic axes or full three-dimensional PBC. If your CV needs molecule reconstruction or a special treatment of periodic images, express it in custom PLUMED input rather than assuming wrapped coordinates are sufficient.

    The scalar fields define one CV. Use cvs for one or two explicit CV definitions in a joint bias. metad_arg changes references; it does not create additional CV definitions. Other combinations or PLUMED actions still use custom input.

    Two CVs and optional hill pauses¶

    from matmalib import mlmd

cvs = (
    mlmd.CVConfig("distance", "DISTANCE", (3, 11), sigma=0.2, unit="angstrom"),
    mlmd.CVConfig("torsion", "TORSION", (1, 5, 17, 23), sigma=0.15),
)
meta = mlmd.MetadynamicsConfig(
    cvs=cvs,
    pause_when=mlmd.DepositionPause.between("torsion", -15, 15, unit="deg"),
    pace=200, height_kj_mol=2, biasfactor=10,
    hills_file="HILLS", colvar_file="COLVAR", save_input="plumed.dat",
)
# Use meta with your existing simulation.run_md(..., MDConfig(...)) call.
print("CVs:", [cv.label for cv in cvs])
print("Grid allocation:", mlmd.validate_metadynamics(cvs)["grid_points"])

    Each CV has its own Gaussian width. Atom indices are one-based; the configured distance width uses Å here and angular widths use radians. Internally, distance values are converted to nm. Grid fields default to None: this example does not impose a fixed distance cutoff or create a bias grid. Torsions retain their physical periodicity on [-pi, pi]. Equivalent dictionaries with the same field names as CVConfig, DepositionPause, and DepositionPauseGroup are accepted, including JSON configuration.

    The example pauses hills while -15 <= torsion <= 15 in degrees, including both endpoints. unit="deg" applies only to these angular thresholds; the torsion width and PLUMED data remain in radians. With unit=None, thresholds use the selected CV's configured units: Å for a distance with unit="angstrom", nm for other distances, and radians for angles/torsions. An explicit threshold unit overrides that default; unit="angstrom" always means Å, including when passing already-normalized CV dictionaries whose canonical unit is nm. Use pause_when=None to disable the pause.

    between is a convenience for two inclusive comparisons combined with all:

    from matmalib import mlmd

interval = mlmd.DepositionPause.all(
    mlmd.DepositionPause("torsion", ">=", -15, unit="deg"),
    mlmd.DepositionPause("torsion", "<=", 15, unit="deg"),
)
print("Pause operator:", interval.operator)

    all(...) requires every condition to hold; any(...) requires at least one. Groups can contain other groups and comparisons on different CVs. For example, pause when distance >= 3.5 Å or the torsion lies within −15° to 15°:

    from matmalib import mlmd

cvs = (
    mlmd.CVConfig("distance", "DISTANCE", (3, 11), sigma=0.2, unit="angstrom"),
    mlmd.CVConfig("torsion", "TORSION", (1, 5, 17, 23), sigma=0.15),
)
pause_when = mlmd.DepositionPause.any(
    mlmd.DepositionPause("distance", ">=", 3.5, unit="angstrom"),
    mlmd.DepositionPause.between("torsion", -15, 15, unit="deg"),
)
meta = mlmd.MetadynamicsConfig(cvs=cvs, pause_when=pause_when)
spec = mlmd.validate_metadynamics(cvs, meta.pause_when)
print("Pause operator:", spec["stop_rule"]["operator"])

    All new hills in the joint bias pause while the complete rule is true, then resume on the next scheduled deposition step after it becomes false. Dynamics, existing bias forces, walls, and COLVAR output continue. Thresholds shown here are examples; select them for your system. The rule requires cvs, which may contain a single CV. Structured controls cannot be combined with input_lines or plumed_file.

    Torsions are compared on their signed [-pi, pi] domain. between requires its lower bound to be no greater than its upper bound. To pause across the periodic seam, use any(torsion >= 165°, torsion <= -165°) as two DepositionPause comparisons, each with unit="deg".

    Portable checkpoints retain both CV definitions, the pause rule, the joint HILLS history and COLVAR output. restart_md restores these without a notebook wrapper, including checkpoints from the earlier AIMNET_METAD_V1 notebook format. Changing from a one-CV bias to two CVs requires a new bias history. Existing checkpoints retain their original labels, pause rules, and grids or grid-free representation. Changing a new-run configuration does not replace the saved rule used by restart_md.

    Grid-free runs save HILLS and COLVAR containing the CVs, accumulated bias and optional pause indicator. They do not emit CALC_RCT, metad.rbias or metad.rct. Reconstruct a two-CV FES from the completed HILLS history:

    fes = mlmd.reconstruct_two_cv_hills(
    "HILLS", cvs, output_dir="hills_fes_2d", bins=(80, 80),
    energy_unit="kJ/mol", temperature_K=300,
)
figure = mlmd.plot_two_cv_hills(fes, distance_unit="angstrom")

    Native PLUMED runs in the same process and infers the analysis extent from the deposited hills. bins sets reconstruction resolution; these analysis bounds do not restrict the simulation. Supplying temperature_K adds marginal profiles by integrating exp(-F/RT) over the other CV within that reconstructed extent. Without it, the result is a surface only. Arrays and plots use the selected energy_unit (kJ/mol or kcal/mol); the raw PLUMED DAT file remains in kJ/mol. Outputs are protected unless overwrite=True; input files are always protected. Distance arrays and numeric artifacts remain in nm. distance_unit="angstrom" changes only displayed distance axes and marginal coordinates; angular axes remain radians.

    This HILLS surface is a full-history bias-based estimate. The helpers cannot derive normalized population reweighting or cumulative reweighted time windows from grid-free COLVAR bias alone. Those diagnostics remain available for runs that recorded normalized bias using an explicit grid, as described below.

    Add an optional wall¶

    from matmalib import mlmd

meta = mlmd.MetadynamicsConfig(
    cv="DISTANCE", atoms=(1, 2),
    wall_type="UPPER_WALLS",
    wall_at=0.6, wall_kappa=150000.0,
    wall_exp=2, wall_eps=1.0, wall_offset=0.0,
)
print("Wall location:", meta.wall_at * 10, "angstrom")
print("Wall action:", meta.wall_type)
print("Energy scale:", meta.wall_kappa, "in generated PLUMED energy units")

    UPPER_WALLS or LOWER_WALLS enables a wall; wall_type=None disables it. With two structured CVs, set wall_arg to the desired CV label. The scalar wall fields retain PLUMED units: wall_at/wall_offset use nm for a distance or radians for an angle, including when a structured distance configuration uses angstrom input. wall_kappa, wall_exp, and wall_eps control the PLUMED wall potential. A strong wall can produce large forces and restrict accessible states; choose its location and stiffness deliberately. The resulting wall.bias is printed by default and matters when interpreting or removing bias in analysis.

    Decide whether to use a grid and normalized bias¶

    Explicit bias grids remain supported when normalized population reweighting is needed. For structured CVs, supply grid_min, grid_max, and grid_bins for every CV, or leave all three unset for every CV. Partial and mixed grids are rejected. Explicit torsion grids must cover [-pi, pi]. Allocation is limited to two million points, counting grid_bins + 1 along each axis.

    Complete grids enable CALC_RCT by default and add metad.rbias and metad.rct to COLVAR. calc_rct=False disables normalization; calc_rct=True without a grid raises. Raw metad.bias alone is never used as a normalized population weight.

    Situation Configuration
    Structured CVs, any supported ensemble Grid-free by default; reconstruct from HILLS.
    Structured CVs with normalized COLVAR analysis Supply complete per-CV grids; retain default calc_rct=None and normalization columns.
    Legacy scalar DISTANCE, fully periodic fixed cell With cvs=None, defaults retain the automatic grid and normalized bias.
    Legacy scalar NPT, nonperiodic distance, angle, or torsion No automatic grid; supply a complete scalar grid for normalization or reconstruct from HILLS.

    Legacy automatic distance bounds use the fixed cell's half-cell corners and a margin related to sigma; grid_spacing controls their resolution. They are not used by grid-free structured CVs. Explicit grids should cover the expected CV range and hill support; a fixed grid can become unsuitable as an NPT cell changes.

    For a completed two-CV run that recorded metad.rbias, load its saved definitions and compute population-reweighted analysis:

    from pathlib import Path

saved_spec = mlmd.read_metadynamics_spec(
    Path("gridded_run/plumed.dat").read_text().splitlines()
)
fes = mlmd.analyze_two_cv(
    "gridded_run/COLVAR", saved_spec["cvs"], temperature_K=300,
    bins=(80, 80), output_dir="reweighted_fes_2d", energy_unit="kJ/mol",
)
figure = mlmd.plot_two_cv(fes, distance_unit="angstrom")
windows = mlmd.plot_two_cv_windows(fes, distance_unit="angstrom")

    This result includes reweighted density/free energy, integrated 1D marginals, cumulative time windows and sampling diagnostics. Normalized input bias uses kJ/mol and time uses ps. Returned arrays use energy_unit; empty bins retain infinite free energy. The two-CV analysis handles periodic torsion samples; the one-dimensional basin API does not support basins crossing a periodic boundary.

    NPT additionally requires full PBC, a finite-volume cell, a stress-capable potential, and no fixed-atom, SHAKE, or center-of-mass constraints. The PLUMED virial contributes to pressure/stress, and the bias is updated once per integration step even if the integrator requests several force evaluations. A time-dependent bias also means that choosing ensemble="NVE" does not yield conservation of the unbiased system's energy.

    5. Supply custom PLUMED input¶

    Use either plumed_file or input_lines. These replace generated CV/bias/wall/PRINT commands; fields such as atoms, sigma, hills_file, and colvar_file no longer define the custom actions or their destinations.

    This configuration defines two distances and a two-dimensional bias. It assumes at least four atoms; pair choices and hill widths must suit your system:

    from pathlib import Path
from matmalib import mlmd

out = Path("custom_bias").resolve()
out.mkdir(exist_ok=True)
meta = mlmd.MetadynamicsConfig(
    input_lines=(
        "UNITS LENGTH=nm ENERGY=kj/mol TIME=ps",
        "d1: DISTANCE ATOMS=1,2",
        "d2: DISTANCE ATOMS=3,4",
        f"m: METAD ARG=d1,d2 SIGMA=0.02,0.02 HEIGHT=1 PACE=300 "
        f"BIASFACTOR=10 TEMP=300 FILE={out / 'HILLS'}",
        f"PRINT ARG=d1,d2,m.bias STRIDE=10 FILE={out / 'COLVAR'}",
    ),
    save_input=out / "plumed.dat",
    log_file=out / "plumed.log",
)
# In your prepared workflow:
# simulation.run_md(ready, mlmd.MDConfig(
#     mode="metadynamics", metadynamics=meta,
#     trajectory=out / "trajectory.xyz", log_file=out / "md.log",
# ))

    Alternatively, mlmd.MetadynamicsConfig(plumed_file="my_plumed.dat", save_input="resolved.dat") reads an existing file. Comments and blank lines are stripped, and PLUMED ... blocks are flattened; nested or unterminated blocks are rejected. save_input stores that resolved input, also available as simulation.data.plumed_input.

    Custom commands control their own paths, units, periodic treatment, and restart directives. Relative output paths are interpreted by the native run, not automatically relative to plumed_file; use explicit paths for reproducibility. Matmalib's generated-output path protections do not inspect every custom FILE action, so use a fresh directory and avoid accidental reuse. The one-dimensional analysis API cannot directly reconstruct this two-dimensional example; use PLUMED tools or a separately prepared one-dimensional marginal grid.

    6. Keep a live bias through equilibration¶

    Ordinary preparation is unbiased unless its own configuration explicitly requests metadynamics. To build the bias during equilibration and continue it during production, use one shared MetadynamicsConfig and continue_equilibration_bias=True in a single run_md call:

    from matmalib import mlmd

simulation = mlmd()
meta = mlmd.MetadynamicsConfig(
    atoms=(3, 11),
    hills_file="continuous_HILLS", colvar_file="continuous_COLVAR",
    save_input="continuous_plumed.dat", log_file="continuous_plumed.log",
)
equilibration = mlmd.EquilibrationConfig(
    steps=2000, timestep_fs=0.5, temperature_K=300,
    ensemble="NVT", thermostat="langevin", thermostat_time_fs=10,
    mode="metadynamics", metadynamics=meta,
    trajectory="biased_equilibration.xyz", log_file="biased_equilibration.log",
    seed=31,
)
simulation.run_md("equilibrated.xyz", mlmd.MDConfig(
    steps=100000, timestep_fs=0.5, temperature_K=300,
    ensemble="NVT", thermostat="langevin", thermostat_time_fs=100,
    mode="metadynamics", metadynamics=meta,
    equilibration=equilibration, continue_equilibration_bias=True,
    trajectory="biased_production.xyz", log_file="biased_production.log",
    seed=31,
))
print(simulation.data.start_step, simulation.data.last_step)  # 2000, 102000

    The live PLUMED instance, hill history, velocities, RNG, and clock continue across the boundary. HILLS/COLVAR remain shared; MD trajectories and logs have separate paths. Thermostat damping may change. Both phases must use identical timestep, target temperature, ensemble, metadynamics settings, and potential; cell/PBC/charge/multiplicity overrides must agree. Seeds must match when both are set. NPT retains the cell reached during equilibration.

    This also supports custom PLUMED input while the process remains alive. It is different from ending equilibrate and then starting an independent run_md: returning a State preserves molecular state but does not preserve a live PLUMED bias. Independent biased phases should use separate bias files unless you implement an explicit native restart workflow.

    7. Restart generated metadynamics safely¶

    By default, checkpoints are written every 1,000 steps and at completion, including biased runs. checkpoint_interval changes the interval and checkpoint_file=None disables them. Save simulation.data.checkpoint_file before performing another operation that replaces .data.

    After the installation check above, run:

    from ase.calculators.emt import EMT
from matmalib import mlmd

simulation = mlmd(calculator=EMT())  # same potential as the original check
continued = simulation.restart_md(
    "metad_check/trajectory.checkpoint.npz",
    steps=50,
    trajectory="metad_check/part2.xyz",
    log_file="metad_check/part2.log",
)
print(continued)
print(simulation.data.last_step)  # 150

    steps means additional integration steps. Restart restores molecular state, constraints, random-generator state, thermostat/barostat variables, and the original step count. Use the same ASE version and model/calculator settings; model weights are not embedded in a checkpoint.

    The new XYZ/log files are separate segments; existing files are protected. For generated PLUMED input, saved HILLS/COLVAR snapshots are copied to part2.plumed/, the saved input is updated to those paths, and native restart continues the bias and output history there. Original files are untouched. HILLS text precision can produce small numerical differences from an uninterrupted biased run.

    overwrite=True is permission to replace output paths during a new run; it is not a continuation or append switch. Use restart_md for checkpoint continuation or continue_equilibration_bias for live phase continuation. Custom PLUMED runs still write molecular-state checkpoints, but restart_md rejects them because arbitrary actions may need additional state beyond HILLS/COLVAR. Handle custom native restart requirements explicitly rather than treating their checkpoint as a complete automatic bias restart.

    8. Inspect the result before analysis¶

    Output Contents
    Extended XYZ trajectory Saved geometry, cell/PBC, masses, momenta, step, and time_fs; streamed to disk.
    MD log Potential/kinetic/total energy, temperature, maximum force, volume, and timing; unavailable model-disagreement fields are nan.
    HILLS Deposited-hill history, used by native bias restart and reconstruction.
    COLVAR CV and available bias columns at colvar_stride; generated times are in ps.
    Saved PLUMED input Resolved action definitions and paths for provenance and analysis.
    simulation.data Status, bounded running statistics, model/system/settings metadata, resolved input, and checkpoint paths.

    In biased runs, potential and total energies in MD diagnostics include the applied bias; they are not an unbiased energy-conservation trace. Inspect CV coverage, numerical stability, hill history, and sensitivity to discarded equilibration and sampling duration before interpreting a FES. Continue to metadynamics analysis for normalized COLVAR reweighting, HILLS reconstruction, and one-dimensional free-energy plots.
