# matmalib documentation

Read the [documentation and interactive tutorials](https://EChung0111.github.io/matmalib-docs/).

This repository hosts the generated website, including the documented Python source and public sample structures used by its interactive examples. The editable documentation and library live in [marianski-lab/matmalib](https://github.com/marianski-lab/matmalib) (source repository access is required).

Updates to the source repository's main branch are validated and published here automatically by its Documentation workflow. Edit the source documentation rather than generated HTML. The source commit is recorded in `source-commit.txt` and each publishing commit message.

GitHub Pages serves branch **main**, folder **/ (root)**. Keep `.nojekyll` and this README when republishing. The source workflow uses a dedicated SSH deploy key with write access to this hosting repository.
